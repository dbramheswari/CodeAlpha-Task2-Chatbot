# 🤖 Simple Chatbot - CodeAlpha Internship Task 2

This is my Task 2 for CodeAlpha Python Internship.

### 📝 About Project
A simple rule-based chatbot built in Python that can respond to user queries with predefined answers. It uses if-else logic to have a basic conversation.

### 🚀 Features
- Greets the user
- Answers basic questions (name, how are you, etc.)
- Handles unknown inputs
- Exit on "bye" command

### ▶️ How to Run
1. Download or clone this repository
2. Run the file: `python chatbot.py`
3. Start chatting with the bot!

### 🛠️ Tech Used
- Python 3
